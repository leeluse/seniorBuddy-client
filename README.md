🌐 ### Go To Senior Buddy <br/> https://senior-buddy.vercel.app/

### 💫 프로젝트 목적
---
디지털 약자 시니어 대상 대화형 AI 비서 애플리케이션을 통한 시니어의 디지털 적응력 향상 개발 배경
- 고령화 사회 진입에 따른 시니어 인구 증가
- 시니어의 디지털 기기 사용 어려움 및 관련 친화적 서비스 부족
- 사투리 등 언어 습관을 인식하여 어르신 맞춤 대화 제공
- 복약 및 병원 알람을 통한 건강 관리 지원
- 맞춤형 디지털 기술 지원을 통한 적응력과 자립성 증대
<br/>
  <br/>

### 🛠️ 프로젝트 핵심 기능
---
1️⃣ **메인 화면**  <br/>
- 시니어용 / 보호자용 화면을 분리해 UX 향상 <br/>

2️⃣ **로그인/회원가입** <br/>
- 이메일 / 전화번호를 통한 회원가입 및 로그인
  

3️⃣ **설명서** <br/>
- 핸드폰 조작에 관한 가이드 제공


4️⃣ **알리미** <br/>
- 복약 및 병원 정보 확인 및 알림 수신
  

5️⃣ **나의 정보** <br/>
- 나의 계정 정보 출력
- 웹 내 폰트 크기 설정
- 다크/라이트 테마 설정

6️⃣ **알리미**  <br/>
- 복약/병원 일정 조회 및 병원 추천, 긴급 구조 요청
- 날씨 및 주변 버스정류장 정보 제공

### 🛠️ 기술 스택
--- 
- Language : TypeScript (React)
- Framework : Next.js
- Package Manager : npm
- CSS Framework: TailwindCSS
- State Manage Framework: zustand
